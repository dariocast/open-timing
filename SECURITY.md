# Security & Privacy Policy

## 🔒 Offline & Privacy Promise

OpenTiming is designed with strict **privacy by design**:
- All activity logs, URLs, document paths, and metrics are stored locally in `~/Library/Application Support/OpenTiming/opetiming.sqlite`.
- OpenTiming does not make any network requests.
- No analytics, metrics, or telemetry are collected or transmitted.

## Reporting a Vulnerability

If you discover a potential security vulnerability (e.g. local privilege escalation, improper handling of accessibility permissions, or data leakage):
1. Please do **NOT** open a public issue.
2. Open a private security advisory via GitHub Security Advisories or contact the repository maintainers.
3. We will respond promptly and work on a fix.
